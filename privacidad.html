Política de Privacidad

Última actualización: Septiembre 2026

1. Datos Recopilados

D-Nexus solo recibe los datos que el usuario decide enviarnos. El formulario de contacto de este sitio no almacena información en nuestros servidores: prepara un mensaje con el nombre, el tipo de proyecto, el presupuesto aproximado y los detalles que el usuario escribe, y lo abre en WhatsApp o en su cliente de correo para que sea el propio usuario quien lo envíe. Una vez enviado, el mensaje se rige también por las políticas de privacidad de WhatsApp o del proveedor de correo utilizado. Además, podemos conocer el número de teléfono o el correo desde el que el usuario nos escribe por cualquier canal directo.

2. Uso de la Información

La información personal recopilada es utilizada exclusivamente para la atención de consultas, elaboración y envío de propuestas comerciales adaptadas a las necesidades del cliente, así como para la gestión integral de la relación comercial durante la prestación de nuestros servicios tecnológicos.

3. Analítica y Cookies

Este sitio web utiliza herramientas de analítica web (tales como Google Analytics) para la medición anónima y estadística del tráfico de visitantes. Estas tecnologías permiten recopilar datos de navegación agregados con el objetivo de optimizar continuamente la experiencia de usuario y el rendimiento técnico de la plataforma. Esto incluye contar, de forma agregada, cuántas veces se pulsa un botón de envío del formulario de contacto, sin registrar el contenido del mensaje.

4. Derechos del Usuario

El usuario puede ejercer en cualquier momento sus derechos de acceso, rectificación, limitación o eliminación de sus datos personales enviando una solicitud formal a través de nuestros canales de contacto oficiales habilitados en este sitio web.

5. Sistemas de Gestión Alojados

Cuando D-Nexus aloja y mantiene un sistema de gestión para un cliente, los datos de su negocio (productos, ventas, clientes y proveedores) se tratan únicamente para prestar el servicio contratado, siguiendo las instrucciones del cliente, que es quien decide qué datos registra. D-Nexus aplica copias de seguridad y control de acceso, no usa esos datos para otros fines y, al finalizar el servicio, entrega una copia al cliente cuando la solicita.
